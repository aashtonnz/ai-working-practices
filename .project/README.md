# This repository's own project

This folder is for working on ai-working-practices itself. It is not a practice, template or example. If you're here from another project, ignore it.

This project follows ai-working-practices: the practices in this repository apply to the repository too. Read the main README at the start of every conversation, and check CHANGELOG.md at least once a day in longer work.

Changes also arrive from other projects, with the owner's approval, and they don't update this folder. At the start of every conversation, catch up: list the commits since the one recorded on the task board ("Caught up to"), add each one made elsewhere to Done with a one-line result and its CHANGELOG entry, and record the latest commit.
