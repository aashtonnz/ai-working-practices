# This repository's own project

The `.project/` folder is for working on ai-working-practices itself. It is not a practice, template or example. If you're here from another project, ignore `.project/`.

This project follows ai-working-practices: the practices in this repository apply to the repository too. Read the main README at the start of every conversation, and check CHANGELOG.md at least once a day in longer work.

Changes also arrive from other projects, with the owner's approval, and they don't update `.project/`. At the start of every conversation, catch up: list the commits since the one recorded on the task board ("Caught up to"), add each one made elsewhere to Done with a one-line result and its CHANGELOG entry, and record the latest commit. A commit can't name itself, so the marker usually trails by one commit made here, whose Done line is already on the board; it needs nothing more.

This project's decisions are changes to the practices, so `CHANGELOG.md` serves as its decision log, with no separate file. A decision that changes nothing is recorded in its task's Done line.

## What you may change without asking

This section applies only if you were asked to work directly on ai-working-practices, as your core project. If your core project is any other project, this section doesn't apply to you, and you should ignore the whole `.project/` folder.

- **You may, without asking:** update `.project/TASKS.md`, add or update other notes inside `.project/` (a decision log, say), and commit and push those changes.
- **You may not, without the owner's explicit yes for that change:** change `.project/README.md` (this file), including this section; change, add or delete anything outside `.project/`; or delete the `.project/` folder.
- **If one change touches both** `.project/` and anything outside it, the whole change needs the owner's yes.

The owner gave this standing approval on 2026-10-18. It doesn't alter the notice at the top of the main `README.md`: it is the owner's explicit approval, given once, for the board and notes in `.project/` only.
